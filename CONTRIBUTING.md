# Contributing

This repository is a personal profile system, but corrections and focused
improvements are welcome.

1. Edit human-owned content in `data/profile.yml`, `data/projects.yml` or
   `data/capabilities.yml`.
2. Do not hand-edit `README.md` or files under `assets/generated/`.
3. Run `pnpm generate`, then `pnpm validate`.
4. Keep claims tied to public repositories, reproducible checks or merged pull
   requests.
5. Never add private repository names, secrets, visitor tracking or
   unverifiable performance metrics.

Pull requests should explain the evidence behind any new capability or project
claim.
