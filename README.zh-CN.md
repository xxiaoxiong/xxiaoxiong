## 系统定位

我是 Nicholas，一名智能体系统工程师。

专注多智能体运行时、本地 AI 基础设施、RAG 与知识系统、企业级 AI
应用和开源工程。我更在意系统是否具有明确状态、受控工具、失败回退和可验证结果，而不是
仅展示一段看起来能够运行的 Agent 对话。

| 能力模块 | 工程证据 |
|---|---|
| **受治理的智能体运行时** | Task Graph、持久状态、工具权限、人工审批、Verifier、修复与重规划 |
| **本地 AI 基础设施** | vLLM、OpenAI 兼容接口、LiteLLM 网关、Docker、Prometheus、Grafana |
| **知识与 RAG 系统** | 文档处理、混合检索、知识审核、本地文件检索、证据化输出 |
| **开源工程** | 双语文档、确定性生成、测试、CI、已被外部仓库合并的 PR |

## 旗舰系统

### 01 / MegaDeepagents

> 一个受治理、可恢复、可观测的多智能体任务运行平台。

它解决的不是“让多个 Agent 聊起来”，而是多智能体在真实工程任务中的状态权威、
原子认领、工具权限、产物验证、失败恢复和 Git 隔离问题。

`LangGraph Root Graph → TaskGraph / TaskBoard → Parallel Scheduler →
DeepAgent Worker → ArtifactStore → Fail-closed Verifier → Repair / Replan`

[项目仓库](https://github.com/xxiaoxiong/MegaDeepagents) ·
[项目介绍站](https://megadeepagents.vercel.app)

### 02 / NICHOLAS / SPATIAL AI WORLD

> 使用持续存在的 Three.js 世界作为个人工程作品集的信息架构。

它不是普通网页中嵌入一个 3D 模型，而是通过六个空间区域、连续相机运动、真实项目入口、
深链接和无障碍 HUD 构成完整的空间浏览体验。

[项目仓库](https://github.com/xxiaoxiong/3DHomepage) ·
[在线体验](https://3-d-homepage.vercel.app/)

### 03 / Awesome Multi-Agent Projects

> 面向全球开源多智能体系统的双语、领域优先研究目录。

结构化数据经过 Schema 校验后，同时生成中英文 README、项目研究页和静态网站，CI
检查数据、渲染、类型、测试、构建与链接，避免目录与网站长期漂移。

[项目仓库](https://github.com/xxiaoxiong/awesome-multi-agent-projects) ·
[研究网站](https://awesome-multi-agent-projects-site.vercel.app)
